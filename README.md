# BE THE GOAT

**BE THE GOAT** is an original browser-based football player career simulator.

You create one player, begin in youth football, and build a career through development, team selection, matches, contracts, transfers, competitions, media, achievements, and retirement.

## Core experience
- Player-focused career simulation; no direct match control.
- Automatically simulated matches presented as highlights, results, ratings, and statistics.
- A dynamic football world with clubs, players, competitions, and transfers.
- Fast calendar progression with consistent career records.
- Local saves as the initial persistence strategy.

## Visual direction
A premium, minimalist sports interface using black, white, and neutral gray.

## Development roadmap
1. Project foundation and development rules.
2. Visual identity, navigation, and first screen.
3. Player creation and career setup.
4. Football data model: players, clubs, leagues, and competitions.
5. Youth career, training, and player development.
6. Contracts, agents, and transfers.
7. Match simulation and highlights.
8. Calendar, seasons, tables, and competition progression.
9. Dynamic world simulation and AI clubs.
10. News, relationships, career history, balancing, testing, and deployment.

Each stage is implemented and reviewed separately. See [AGENTS.md](./AGENTS.md) for mandatory development rules.
